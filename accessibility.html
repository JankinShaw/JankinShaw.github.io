Accessibility

Using this
website.

Information about accessible features, display options, and known limitations.

Available features

This website is designed to work with keyboard navigation, screen readers, browser zoom, and operating-system accessibility preferences.

  • The Accessibility button offers text-size, high-contrast, and reduced-motion options.
  • Easy Read provides a simpler introduction to the website and its main content.
  • Pages use headings, landmarks, descriptive links, and alternative text for meaningful images.
  • Essential content and navigation do not require a mouse.
