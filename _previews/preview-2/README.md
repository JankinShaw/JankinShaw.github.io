# Minimal blog preview

Independent local experiment inspired by https://lordtoots.bearblog.dev/ . This is Jekyll, not Bear hosting. This design has now been integrated into the live blog; this folder remains an independent snapshot.

Double-click `Preview.command` in this folder. It uses ports 18523–18543; keep Terminal open while previewing. Uses the root Gemfile dependencies.

Home introduction and About were copied from the live blog. `_posts/` and `_blog_archive/` are snapshots of the current content, not the writing source of the published blog. Edit the root `_posts/` for publication. To refresh the experiment, copy those Markdown files into the matching folders here. No analytics are loaded. The whole folder stays unpublished because Jekyll excludes underscore directories by default.

Body uses device Verdana (then Geneva, sans-serif); headings use system UI fonts. Colors follow the system light/dark preference. RSS is generated locally from these copied posts. Formula rendering uses the same MathJax configuration as the live blog.
