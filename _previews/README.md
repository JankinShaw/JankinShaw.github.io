# Local blog previews

- `preview-1/`: preserved original Journal prototype. Run `bash _previews/preview-1/serve.sh` from the repository root (port 4001).
- `preview-2/`: preserved minimal design experiment. Double-click `preview-2/Preview.command` (starts at port 18523).

Both contain independent content snapshots. Edit root `_posts/` for the live blog. Root `Preview.command` previews the actual current website at `/blog/`. Nothing here is published by Jekyll; the parent folder begins with `_`.

Complete recoverable architecture snapshots live separately in `_archive/blog/versions/`.
